Add your own case with the form (simple cases can be corrected later with Edit), load a synthetic scenario, or upload traces (JSONL/CSV; use upload or ✎ JSON edit for rich tool traces). Human labels are 1–5.

Upload file format + starter template One case per line or row.
  • Needed per case: query (the user request; input, question or messages also work) and response (the agent's answer; output or answer also work). Give each case a unique id; a missing, empty or 0 id gets a generated one starting with row-.
  • Optional: context (grounding text; needed for Groundedness unless the answer has a tool result), tool_definitions or tool_calls (one is needed for Tool Call Accuracy unless the answer has tool calls), scenario, note. The request and answer may be plain text or a Foundry / OpenAI message list; in a CSV, put JSON inside the cell.
  • Human labels (optional): whole numbers 1–5 in human_intent_resolution, human_task_adherence, human_tool_call_accuracy, human_groundedness (or <metric>_label). Blank means no label, never 0. Other non-blank columns are kept as they are.
