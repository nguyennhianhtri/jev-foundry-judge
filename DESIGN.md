# DESIGN.md: Jev Foundry Judge

This is the single source of design values for `app/static/`. Colours, radii and motion come from the CSS custom properties in `styles.css` `:root` / `[data-theme=light]`. Don't add one-off hex or px values. If you need a new value, add a token here and in `:root` first.
Style: Fluent-ish, dark first, with an equivalent light theme (toggle: `#theme`, `html[data-theme]`).

## Type
Family: `"Segoe UI Variable","Segoe UI",system-ui,-apple-system,sans-serif`. Mono: `ui-monospace,Menlo,Consolas,monospace`.
Scale (px): **11.5** tag/caption · **12 / 12.5** hint, table head, code · **13** table body · **14** body (base, line-height 1.45) · **15** h3, hero lede, big button · **21** h2 (browser default for h2 at 14px base) · **26** KPI value · **30** h1 (hero only, line-height 1.2).
Weights: 400 body, 600 labels/buttons/th, 700 KPI values, 800 logo mark. Numbers use `font-variant-numeric: tabular-nums`. Keep line length to about 820px max for prose (`.hero p`, `h1`).

## Spacing
The 4px base scale is **4 · 6 · 8 · 10 · 12 · 14 · 18 · 22 · 40**.
- Card padding is 16×18. The gap between cards and grid gutters is 14. Row gap is 8–10.
- Page padding is 22 (12 under 600px) and page max width is 1280.
- Header padding is 10×22 (8×12 at ≤900px).
- Header reflow: the header wraps (brand · steps · version/theme) rather than overflowing; step labels never break mid-label and at ≤900px the step row wraps into rows (never a clipped scroll strip). If the header grows past 25% of the viewport height (enlarged text), it gets `.top.tall`: not sticky, and above 600px the steps wrap into rows; step changes then scroll to the panel. Theme toggle is always ≥ `--tap`.

## Radius
`--r` 12px for cards, dialogs, KPI tiles and table wrappers. `--r-sm` 8px for buttons, inputs, code blocks and step items on mobile. 999px for pills, tags, the desktop stepper and progress bars. Score pills use 6px, and the logo mark uses 8px.

## Motion
`--dur` 0.18s is used for colour, border, shadow and press transforms. Panel/tab switch: `f` 0.25s fade-up. Dialog open: `dlg` fade and scale. `details` open: fade. With `prefers-reduced-motion: reduce`, all animation and transition is disabled.

## Components
**Button** (`button`, `.btn`, `label.btn`): `--bg2` fill, 1px `--line` border, radius `--r-sm`, padding 8×14, inherits font.
- Variants:
  - `.primary` uses `--acc-fill` with `--on-acc` text at weight 600. **One primary per step.** The Dataset step demotes `+ Add case` once `Next: Run step →` shows.

  - `.big` is padded 11×22 at 15px.
  - `.linkish` is an inline text button in `--acc`, underlined.

  - Hover: border `--acc`, or `--acc-fill-hover` for primary.
  - Pressed: 1px translate plus an accent-tinted fill.
  - Disabled: opacity 0.5 with `not-allowed`.

Invalid fields use `[aria-invalid=true]` with a `--bad` border/outline, and the message shows inline in `.err` directly under the field. Checkboxes are 18px (22px on touch) with `accent-color: var(--acc-fill)`.
